# cad-toy-robot
I created a toy robot in this project via OnShape. It's *small* enough to be 3D printable, and it easily scales to <ins>whatever size you want</ins>. I decided to make this project so that I can mass-print them and give them out to kids for **free** if I'd like to. I think it would be a very kind thing to do. It was also fun to create and design this unique robot.

BOM:
Bambu Lab Silver PLA Basic (or any other colors)
